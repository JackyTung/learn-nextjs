# 🚀 Next.js 學習筆記與實作

這是我用來學習 Next.js 的專案空間。包含來自 Next.js 官方文件、Udemy 課程以及其他資源的學習紀錄與實作專案。

## 📂 資料夾結構說明

- 📁 **`official-tutorial/`**: Next.js 官方網站與教學課程 (例如 Dashboard App) 的練習。
- 📁 **`udemy/`**: Udemy 課程章節的練習與專案，依據章節或主題命名。
- 📁 **`playground/`**: 沙盒測試區，用來實驗特定功能或套件的小專案。
- 📁 **`docs/`**: 純文字的學習筆記、有用的資源連結等。

## 🛠️ 常用指令 (建立新專案)

在此目錄下建立全新的 Next.js 子專案，請進入對應資料夾後執行：

```bash
# 1. 進入目標資料夾 (例如 udemy)
cd udemy

# 2. 使用 create-next-app 建立專案
npx create-next-app@latest my-project-name

# 3. ⚠️ 重要：移除子專案的 .git (避免產生 submodule，讓外層統一控管)
rm -rf my-project-name/.git
```
